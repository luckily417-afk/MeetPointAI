## 六、需要注意

1. `dist\MeetPoint AI\.env` 内含真实 Key，**不要外发**该目录；如需分享，删除 `.env` 并改用 `.env.example`。
2. 高德免费额度有限：单次 3 km 圆形推荐约消耗 100 次调用（36 块检索 + 40 次路线 + 若干地理编码）。大范围请调大 `MPAI_TILE_KM` 或缩小半径。
3. 公共交通对 < 2.5 km 的行程通常无方案，程序会自动改用真实步行路线并标注。
4. DeepSeek 推理模型单次排序约 20–70 秒（已设 `reasoning_effort=low`、`max_tokens=8000`），期间界面进度条与阶段文案可见，可随时「取消当前任务」。
