## 1. 这块屏幕要回答的问题

**“在两个人都能接受的见面地点里，哪一个是公平的？”**

一句话发现（推荐完成后显示在标题下方，不再藏在表格里）：

> 最佳 星巴克臻选（恒隆广场店）· 两端共 35 分钟 · 相差 7 分钟 · 6 个候选

主数据元素（本产品独有）：**双端通勤对比条**。每一行的 A 端（唯一数据色 `#1d5fbf`）与
B 端（同组灰 `#9aa0a6`）用同一把比例尺画成 3px 细条，谁更远一眼看得到，不必逐格读数字。
详情面板里同样的两条搬到 20px 的数字下面，并给出「共 N 分钟 · 相差 N 分钟」的结论句。

产品标记：两个出发点收束到同一个见面点（`ui/widgets.py::ProductMark`），出现在顶栏左侧。

色彩预算：`#1d5fbf` 只覆盖整屏 **0.18%** 的像素（3637 px，1440×900）；旧界面彩色像素占 39%
（饱和地图样式 + 蓝色按钮/胶囊/进度条）。新界面没有渐变、没有投影、没有玻璃。

## 4. 布局算术

```
窗口 1440 × 900
 顶栏 48 · 菜单 27 · 状态栏 24 · 标题行 62
 左表单列 352（20 + 316 内容） + 1px 分隔 + 右栏 1087
 右栏内容 1048 = 20(左) + 1008 + 20(右)
   地图 : 结果 = 52 : 48（可拖拽）
   结果内：表格 671 + 1px + 详情 376（详情宽 = clamp(264, 36%, 420)）
   表格列：34(#) + 拉伸(地点) + 126(A) + 126(B) + 86(总时长) + 66(换乘)
 窄窗（<1280）：表单 316、地图/结果不变；表格隐藏「换乘」「总时长」，A/B 列收窄到 96
```

左侧表单在 1440×900 下**整屏可见**（出发位置 / 出行与偏好 / 推荐区域 + 底部主操作），
不需要滚动；在 1100×760 下只有「推荐区域」需要滚动。

## 5. 改了什么（旧 → 新）

1. **结构性**：三张带圆角边框的 `QGroupBox` 与 ①②③ 序号 → 无卡片的表单分区（小标题 + 字段），
   每个出发地的「地图选点 / 清除」移到标签行，省掉两整行。
2. **主操作**：蓝色大按钮 → 近黑主按钮「开始推荐」，固定在左栏底部；「取消当前任务」改为文字动作。
3. **通勤对比**：旧表格是「14 分钟 / 4.2 公里」两列纯文字（还被截断）→ 两行地点单元（名称 + 类型·商圈·差值）
   + 等宽数字右对齐 + 同尺度对比条 + 总时长 + 换乘（0 次写作「直达」）。
4. **详情**：`QTextBrowser` 里的裸 HTML 表格 → 真实控件：两端通勤列（20px 数字 + 条形）、
   结论句、推荐理由、地点信息（右对齐键值行）、路线步骤、两个文字动作（在高德查看 / 从 A 出发导航）。
5. **状态**：21px 蓝色进度条 → 3px 墨色进度线，完成后自动收起；空态、已取消、失败（提示条）、
   旧结果失效各有文案；空结果时表格换成一句空态说明。
6. **服务状态**：三个填充绿胶囊 → 6px 状态点 + 服务名 + 延迟，正常态不再重复写「正常」。
7. **地图**：饱和底图 + 橙/红/紫三色标记 → 灰白底图、A/蓝、B/墨、结果白底墨圈编号、选中反白、
   区域 1px 虚线灰；`showResults` 现在同时把 A、B 纳入视野。
8. **设置对话框**：旧标签页样式与内联灰字 → 与主界面同一套 tokens（下划线标签、近黑保存按钮、
   带箭头的数字框），并改为 App 级样式表，任何入口打开都一致。
9. **字体**：系统默认 微软雅黑 13px → 随程序分发的 Geist（拉丁/数字）+ 微软雅黑（中文），
   表格与数字用等宽数字，避免数字列抖动。
10. **响应式**：<1280px 收窄表单列与表格列、结果/详情比例自适应；表格窄时允许横向滚动而不再裁切。

## 6. 状态覆盖

| 状态 | 处理 |
| --- | --- |
| 空（未推荐） | 表格区居中一句「还没有推荐结果」+ 一句怎么做；详情列给一句中性说明 |
| 运行中 | 标题下 3px 进度线 + 状态栏文案（「正在检索第 3/4 块…」） |
| 完成 | 摘要「6 个 · 候选 27 个 · 双方可达 27 个 · 用时 6.4s」+ 来源「AI 综合推荐」 |
| 无结果 / 失败 | 静音提示条（琥珀 / 红）+ 状态栏一句；旧结果自动失效并清空 |
| 未配置 Key | 顶部提示条 + 首次运行引导打开设置 |
| 窄窗口 | 见第 4 节；表格列自适应，详情列可拖拽 |

## 7. 演示数据（上线前需替换）

`scripts/ui_preview.py` 里的 `DEMO` 与 `REASONS` 是**只用于截图**的天津样例（星巴克臻选、西西弗、
Manner、Tims、Seesaw、漫咖啡），路线分钟数、距离、评分、人均都是编的，不会进入真实流程；
真实运行时这些字段全部来自高德与 DeepSeek。跑 `python scripts/ui_preview.py --out docs/preview`
可以随时重出一组对照图，不调用任何外部 API。
