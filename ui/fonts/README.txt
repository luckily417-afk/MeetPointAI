Geist / Geist Mono
==================

这些 TTF 随程序一起分发，用于界面拉丁字母与数字：

- Geist-Regular.ttf / Geist-Medium.ttf / Geist-SemiBold.ttf / Geist-Bold.ttf
- GeistMono-Regular.ttf / GeistMono-Medium.ttf

字体：Geist（Vercel），许可：SIL Open Font License 1.1。
来源：Google Fonts（https://fonts.google.com/specimen/Geist 、https://fonts.google.com/specimen/Geist+Mono），
以 `Mozilla/5.0` UA 请求 `fonts.googleapis.com/css2` 得到 truetype 直链下载。

OFL 允许随软件分发与嵌入；如需替换字体，只要保持 `ui/theme.py::install_fonts()` 的族名回退逻辑即可。
